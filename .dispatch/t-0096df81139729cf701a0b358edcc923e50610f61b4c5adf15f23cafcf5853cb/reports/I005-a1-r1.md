**How it works now**
- **What a profile is:** an existing `tags/<name>.toml` layer. There's no new manifest key, and no user repo gets rewritten.
- **Where the choice lives:** on the machine, as an optional `profiles` list in `<state>/machine.toml`. It's only written when at least one profile is chosen.
- **Machines still declared in `[machines]`:** they keep their tags, and any profiles they choose come after those. Their own machine layer still applies last. A declared machine with no profiles behaves exactly as before.
- **No terminal:** `init` asks nothing and picks no profile; `--profile work` chooses up front. Clearing the choice takes `loadout profile set --none`.
- **Unknown or removed profiles:** choosing a profile the loadout doesn't have is refused and nothing is saved. If the loadout later drops a profile a machine uses, plan, apply and sync stop with exit 3 and remove nothing.
- **Interrupted setup:** if you press Ctrl-C at the profile prompt, the machine's name and repo URL are already saved. `loadout profile set`, then `loadout sync`, finishes the setup.
