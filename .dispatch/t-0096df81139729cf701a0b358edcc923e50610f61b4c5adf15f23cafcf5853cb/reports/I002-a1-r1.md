**Decisions**
- **Spinners go to stderr only, and only when it's a terminal.** They never appear in a background run, so the report lines on stdout don't change.
- **Installs that may ask for a `sudo` password get a plain line instead:** "…, elevated: it may ask for a password". A spinner would draw over the password prompt.
- **The spinner erases itself with spaces rather than escape codes, and never hides the cursor.** Older Windows consoles print escape codes as literal text.
- **Ctrl-C leaves the interrupted step's line on screen,** e.g. `⠦ installing cargo a (1/2) ^C`. Clearing it would need a signal handler. The crate forbids `unsafe`, and blocking the signal would be inherited by the installers, so this isn't fixed in this PR.
